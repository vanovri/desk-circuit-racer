# Bounded scene-to-game prompt template

This is a template, not an autonomous model-run record.

```text
Build an arcade desk circuit from approved, explicitly sourced annotations.
Keep nominal centimeters consistent across geometry, car, collision and speed.
Freeze tests, the independent referee, scene provenance and clearance thresholds.

Generate a closed six-gate route that passes the independent segment and full
target-disk referee. Use fixed-timestep motion and swept collision. Preserve ordered
gates, restart/pause, keyboard and touch, and a chase camera. Use own/licensed assets.

Require the guided controller to complete one real model lap without position
teleporting or impacts. Run all Python/Node tests, preserve the actual trace and
hashes, rebuild the standalone HTML, and check it for embedded data/script syntax.
Check WebGL and control behavior on the authorized development page.

At most five edit/check attempts and twenty minutes. Unknown geometry, impossible
routes and failed checks must remain failures. Never invent photo calibration,
mission-like physical accuracy, model calls, completed browser tests, or metrics.
Do not upload private photographs, call external AI services, or publish posts.
```
